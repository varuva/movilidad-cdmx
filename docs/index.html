Concepto

El proyecto Movilidad CDMX nace de la necesidad de centralizar y difundir información relevante sobre los distintos modos de transporte que operan en la Ciudad de México. Se pretende crear una plataforma accesible tanto para habitantes como para visitantes, donde se explique el funcionamiento, las ventajas, y las problemáticas asociadas a cada sistema.

Además de describir las opciones disponibles, el concepto abarca la idea de interconexión entre sistemas, la sostenibilidad y la importancia de una movilidad inclusiva. Se busca promover decisiones informadas y fomentar el uso de medios de transporte más limpios y eficientes.

Arquitectura

La arquitectura de esta documentación sigue un modelo sencillo de páginas estáticas enlazadas mediante navegación de ancla. El objetivo es facilitar su mantenimiento y permitir una rápida publicación en cualquier servidor web o repositorio estático.

Los recursos visuales y estilos se separan en hojas de estilo externas ubicadas en la carpeta css, mientras que los elementos multimedia residirán en img. La estructura permite escalar con subsecciones adicionales o documentos relacionados sin alterar la base.

Sistema Visual

El sistema visual define la identidad gráfica del proyecto. Incluye tipografías, paletas de colores, iconografía y reglas de uso que deben seguirse para asegurar coherencia en todas las piezas comunicativas.

Se establece una tipografía principal (obtenida a través de Typekit, como se aprecia en los enlaces de las cabeceras) y una serie de colores institucionales inspirados en la señalización urbana de la CDMX. Los ejemplos de aplicación abarcan desde botones y encabezados hasta tarjetas informativas.

Tecnología

Esta documentación utiliza tecnologías web estándar: HTML5, CSS3 y, opcionalmente, JavaScript para mejoras de interacción. No se depende de frameworks pesados para mantener la carga ligera y la compatibilidad con navegadores antiguos.

El contenido estático se puede complementar con scripts que manejen el comportamiento del menú o la carga de datos externos (por ejemplo, horarios o estadísticas en formato JSON). Sin embargo, el núcleo de la información permanece accesible sin JavaScript.

Bitacora

La bitácora recoge los cambios realizados en el proyecto a lo largo del tiempo. Cada entrada debe incluir la fecha, la descripción de la modificación y, si es pertinente, el autor.

Es una herramienta útil para desarrolladores y colaboradores que deseen conocer el historial de actualizaciones, decisiones de diseño o correcciones importantes. Esta sección se puede mantener manualmente o a través de un sistema de control de versiones.
